# Asset Management System

Sistem Informasi Manajemen Asset berbasis web menggunakan Laravel 13 dan TailwindCSS.

Project ini dibuat untuk kebutuhan Tugas Akhir dengan studi kasus perusahaan manufaktur. Sistem mendukung pengelolaan asset perusahaan, tracking penggunaan asset, maintenance, stock opname, hingga request asset oleh karyawan.
